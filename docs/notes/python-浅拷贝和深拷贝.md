# python 浅拷贝和深拷贝

1.所谓浅拷贝只是对引用的拷贝（只拷贝父对象）

  


2.所谓深拷贝就是对对象的资源进行拷贝

  



```
    user1@ubuntu:~$ python
    Python 2.7.3 (default, Sep 26 2013, 20:03:06)
```
