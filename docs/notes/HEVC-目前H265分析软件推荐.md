# 【HEVC】目前H265分析软件推荐

1，Codecvisa： <http://codecian.com/>   
国产软件，从最早的H264visa发展至今，感觉从刚开始的玩票，发展到今天专业级别的商业软件，值得支持。   
软件试用版30天试用，20帧限制。   
优点：QT开发，跨平台   
缺点：性能，功能，风格，专业程度和真正大牛级别的商业软件相比还是有距离。   
  
2，Elecard HEVC Analyzer： [http://www.elecard.com/en/produc ... /hevc-analyzer.html](http://www.elecard.com/en/products/professional/analysis/hevc-analyzer.html)   
不多介绍，做过264的都知道，略感失望，与EC传统风格“迥异”   
  
3，Zond 265： <http://www.solveigmm.com/en/products/zond/>   
需要安装chroma，界面简洁，内容丰富，性能稳定性待测   
  
补充：   
Parabola Explorer： <http://www.parabolaresearch.com/explorer-hevc-analyzer.html>   
目前可以有online版本： [http://demo.parabolaresearch.com ... 3-4-5-1-2-2-1-2-3-2](http://demo.parabolaresearch.com/hevc/explorer/1.9.1/sintel/analyzer.html?node=node-1-3-3-4-5-1-2-2-1-2-3-2)   
外观漂亮   
codecvisa也有类似的online版本，在线版本普遍功能有限   
  


都是很贵的软件啊。。。
